# 当前问题记录

## UI-001：首页广告卡片未被屏蔽

- 状态：待修复
- 发现版本：0.1.2
- 页面：首页推荐流
- 实际表现：开启界面优化与“收起明确广告卡片”后，营销推广内容仍正常显示。
- 截图样例：标题“万镜一刻 短剧漫剧，广告营销 零门槛制作，限时优惠39元/首月”，副标题“一站式视频创作平台”。
- 预期表现：此类具有明确营销推广性质的首页卡片应被自动收起，且不留下空白占位。
- 初步排查方向：现有广告识别只检查有限的卡片选择器、`广告/推广`文本边界和 `ad-tag` 类名，未覆盖该版首页推广组件的 DOM 结构及标识。

## UI-002：首页直播推荐卡片未被屏蔽

- 状态：待修复
- 发现版本：0.1.2
- 页面：首页推荐流
- 实际表现：开启界面优化与“收起直播推荐卡片”后，带有“直播”和“直播中”标记的直播卡片仍正常显示。
- 截图样例：“九月全勤DAY4”，卡片左上角显示“直播”，标题前显示“直播中”。
- 预期表现：直播推荐卡片整体自动收起，后续动态加载或换一换产生的直播卡片也应继续被收起，且不留下空白占位。
- 初步排查方向：现有直播识别对文本边界和类名的判断过窄，并可能没有覆盖新版首页卡片最外层容器。

## UI-003：中文输入产生乱码、误屏蔽和空白占位

- 状态：0.1.3 已修复，待真机验证
- 实际表现：中文输入法组合阶段的拼音中间值被逐字保存；短规则误命中大量卡片，且规则变化后旧隐藏结果没有恢复。隐藏内部卡片元素时，外层网格占位仍保留。
- 修复：规则改为编辑后手动“保存并应用”；支持中文逗号、英文逗号和换行；每次应用前恢复旧结果并重新计算；隐藏网格布局项，使剩余推荐正常回流补位。
- 新增规则：支持“任一满足（析取/OR）”和“全部满足（合取/AND）”。

## 后续验收要求

1. 首次进入首页即可处理已存在的广告与直播卡片。
2. 滚动加载、刷新推荐和站内跳转后仍持续生效。
3. 关闭相应选项后，插件隐藏的卡片能够恢复。
4. 不误伤普通视频卡片。

## TIME-001：多页面计时缺少后台统一仲裁

- 状态：待修复
- 发现版本：0.1.2
- 当前表现：普通标签页主要依靠前台焦点避免重复计时；画中画与另一个前台 B 站页面同时满足条件时，仍可能由两个内容脚本分别上报。
- 学习模式：会话和白名单能够同步到全部 B 站标签页，非白名单页面会被拉回允许的视频。
- 尚存差距：学习时长仍由页面心跳推进，不是完全独立于播放、暂停和页面焦点的后台客观时钟。
- 预期表现：由后台统一判定同一浏览器实例的有效计时来源；严格学习会话按客观经过时间推进，同时所有 B 站标签页继续受同一白名单约束。

## TIME-002：视频观看后小时统计仍为 0

- 状态：调查中
- 发现版本：0.1.2
- 实际表现：视频连续观看数十分钟后，对应小时仍显示 0。
- 已确认界面问题：0.1.2 的统计页只在首次进入时读取一次数据，页面保持打开时不会自动刷新；0.1.3 已改为每 5 秒刷新，并在不足 1 分钟时显示秒数。
- 仍需真机复测：刷新已打开的 B 站标签页后连续播放 2 分钟，确认当小时总时长持续增加。扩展安装或更新前已经打开的 B 站页面不会自动获得新内容脚本，必须刷新一次。
- 后续排查方向：内容脚本注入状态、播放器识别、页面焦点条件、心跳上报和后台写入。
