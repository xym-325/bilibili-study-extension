# 当前问题与验收状态

## 0.1.4 已在代码中处理

- 推荐屏蔽改为只检查新增或发生变化的卡片；广告、直播、内容类型、营销和标题关键词分别统计，被收起的网格项不保留空白占位。
- 内容类型支持番剧、国创、纪录片、电影、电视剧、综艺和漫画；关键词只匹配标题，并提供“包含任意一个”和“同时包含全部”两种方式。
- 营销规则只接受明确商品链接/购买按钮，或标题中销售对象与购买引导同时出现。小火箭、普通外链、低播放量、普通报名按钮和正常赞助均不能单独触发。
- 旧版本遗留的行内隐藏样式会在升级后清理，避免规则变化后仍留白。
- 多标签页上报在后台按时间区间去重；观看统计页每5秒刷新，主图显示滚动近七天并可查看单日小时分布。用户已确认计时功能没有明显问题。
- 学习会话改为后台客观时间；同一BV全部分P允许，其他B站标签页受同一白名单约束，时间结束静默解锁。
- 队列接受BV号、普通视频链接和课堂链接，并尝试自动读取标题与封面；功能设置不再重复展示学习模式和观看队列开关。

## 仍需真实浏览器验收

B站会持续调整推荐卡片的DOM结构，构建测试无法证明当前线上页面的每一种广告、直播和类型角标都能被识别。请在扩展管理页重新加载0.1.4并刷新已打开的B站页面，然后用“界面优化”里的本页检查结果核对：已检查数量、各原因收起数量和最近收起列表。未识别的真实样本需要保留页面截图及其卡片DOM，才能安全补充选择器而不误伤普通视频。

重点复测以下场景：

1. 首次进入首页、滚动加载和“换一换”后的广告、直播及类型角标。
2. 被收起卡片的位置由后续视频正常补位，关闭选项或单条恢复后立即还原。
3. 盗月社等正常赞助内容保留；只有小火箭或普通报名入口的卡片保留。
4. 两个B站窗口同时打开时总时长不重复，学习模式会约束全部B站标签页。
