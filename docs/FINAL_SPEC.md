# 最终功能规格（基础交付版）

## 七项功能

1. 界面优化：收起明确广告、直播、用户指定类型角标和严格规则确认的营销推荐；不隐藏普通导航。营销判断不读取评论和封面，不把小火箭、低播放量、普通外链或正常赞助单独作为屏蔽依据。标题关键词支持“包含任意一个”和“同时包含全部”，只匹配标题；被收起的卡片可按条恢复，剩余推荐回流补位。
2. 观看时长：分别记录B站总时长、学习模式和直播；首页等闲逛也计入总时长。主图展示滚动近七天，点击日期查看当天小时分布；保留8周小时明细和长期月度累计。
3. 严格学习模式：用户从本地队列选择一个视频和10分钟至6小时，二次确认后锁定B站白名单；同BV全部分P可看，暂停、记笔记和切换到Obsidian均不暂停客观计时。全部B站标签页受同一会话约束。结束时静默解锁，不发声、不弹窗、不停播，用户可以继续观看。
4. 观看队列：通用队列，不专属于学习模式；分为稍后看、近期观看、到期待处理和已完成，自动读取标题与封面。近期队列5个/3小时为软上限，不自动删除失效或到期项目。
5. 播放器增强：只增加AB循环、范围保存和可配置快捷键，不重复B站的回听、倍速、全屏等功能。
6. 内容过滤：本地关键词命中的弹幕隐藏、评论折叠并允许展开；不使用AI或账号画像。
7. 学习沉淀：保存时间点、AB片段、重点/疑问/待复习标签和分P进度；不截图、不下载视频、不自动联动Obsidian。

## 数据、权限与异常

- 无插件账户、无服务器和云同步；不读取Cookie、Token或任何非B站网页。
- 完整JSON备份采用验证后覆盖，不自动合并；不包含正在进行的学习会话。
- 各类数据可分别清空，互不连带；全部清空需两次确认。学习未结束时只允许导出。
- 版本升级自动迁移；失败时保留旧键数据并以全功能关闭安全运行。
- 锁屏停止计时；多标签页同一实际时间最多累计一次。视频全部失效时仍在白名单错误页按客观时间继续，避免死锁。
- 功能缺权限时首次提醒；之后只在用户再次主动使用该功能时提醒。任何新权限必须重新讨论。
