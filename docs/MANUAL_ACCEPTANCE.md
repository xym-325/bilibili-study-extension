# 手动验收清单

目标浏览器：最新版 Chrome 和 Edge 桌面端。不验收 Firefox、Safari、手机端或B站客户端。

- 首页：明确广告、直播、指定类型角标和满足严格营销规则的卡片收起；剩余卡片补位，导航保留，关闭功能后恢复。
- 屏蔽边界：小火箭、普通外链、低播放量、普通报名按钮和正常赞助不能单独触发；明确商品链接/购买按钮，或销售对象与购买引导共同出现时才收起。标题关键词分别验证“包含任意一个”和“同时包含全部”。
- 动态页面：滚动、换一换和站内跳转后只处理新增或变化卡片，不出现持续高CPU占用；最近屏蔽记录可恢复。
- 计时：首页可见10秒后计时，5分钟无操作停止；正在播放/画中画不被普通空闲误停，锁屏停止。
- 学习：只允许选择一个队列视频；单P、多P和课堂均可加入；同BV所有分P放行，其他B站标签页跳回白名单，登录/验证页放行；暂停视频和切换到其他软件后客观计时继续，结束时静默解锁。
- 队列：输入BV号、普通视频链接或课堂链接后自动显示标题和封面；同BV不重复，到期不删除，90%及全分P逻辑正常。
- 播放器：AB循环、清除、快捷键、时间点暂停和片段自动循环正常。
- 过滤：关键词弹幕隐藏，评论折叠后可手动查看。
- 数据：导出、预览、覆盖导入、六项分别清空和两次确认全部清空正常；未结束学习期间破坏性操作不可用。
- 统计：新安装默认开启；主图为滚动近七天柱状图，点击每天可看24小时分布，总时长、学习模式和直播分别累计；两个同时满足计时条件的B站标签页不重复累计。
- B站DOM不匹配时安全失败：不删除未知节点、不循环刷新、不阻止视频播放。
