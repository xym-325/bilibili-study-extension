# 手动验收清单

目标浏览器：最新版 Chrome 和 Edge 桌面端。不验收 Firefox、Safari、手机端或B站客户端。

- 首页：明确广告/直播/指定标签卡片收起，导航保留，关闭功能后恢复。
- 计时：首页可见10秒后计时，5分钟无操作停止；正在播放/画中画不被普通空闲误停，锁屏停止。
- 学习：单P、多P和课堂均可加入；未选视频、首页、搜索和空间跳回白名单；登录/验证页放行。
- 队列：三个入口可加入，同BV不重复，到期不删除，90%及全分P逻辑正常。
- 播放器：AB循环、清除、快捷键、时间点暂停和片段自动循环正常。
- 过滤：关键词弹幕隐藏，评论折叠后可手动查看。
- 数据：导出、预览、覆盖导入、六项分别清空和两次确认全部清空正常；未结束学习期间破坏性操作不可用。
- B站DOM不匹配时安全失败：不删除未知节点、不循环刷新、不阻止视频播放。
