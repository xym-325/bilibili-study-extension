# B站综合插件

面向 Chrome / Edge 桌面端的本地 Bilibili 学习辅助扩展。基于 Manifest V3、TypeScript、React 和 Vite，不需要插件账户或自建服务器。

## 功能

- 界面优化：收起明确广告、直播、用户选定类型和满足严格规则的营销卡片；支持标题关键词和单卡恢复，剩余推荐自动补位。
- 观看统计：B站总时长、学习模式、直播三项，并提供近七天日度柱状图、单日小时分布与月度累计。
- 严格学习模式：从队列选择一个视频和10分钟至6小时，二次确认后按客观时间锁定B站范围。
- 观看队列：通用的稍后看、近期观看、到期待处理与进度联动，并自动读取视频标题和封面。
- 播放器增强：AB循环、范围保存与快捷键。
- 内容过滤：本地关键词弹幕隐藏与评论折叠。
- 学习沉淀：时间点、AB片段、标签和分P课程进度。

完整决策见 [docs/FINAL_SPEC.md](docs/FINAL_SPEC.md)，真实浏览器验收见 [docs/MANUAL_ACCEPTANCE.md](docs/MANUAL_ACCEPTANCE.md)。

## 开发与加载

```bash
npm install
npm run check
```

然后打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，加载项目中的 `dist/` 目录。不要加载源码根目录，因为浏览器不能直接运行其中的 TypeScript/TSX 文件。

## 权限

| 权限                       | 用途                                                         |
| -------------------------- | ------------------------------------------------------------ |
| `storage`                  | 保存设置、队列、统计、片段、进度和学习会话                   |
| `alarms`                   | 每日检查到期项目、清理超期小时明细并在学习时长结束时静默解锁 |
| `idle`                     | 识别设备锁屏并停止计时                                       |
| `tabs`                     | 仅查询匹配 `*.bilibili.com` 的标签页，同步学习锁定状态       |
| `https://*.bilibili.com/*` | 在B站子域名上执行计时、锁定和页面功能                        |

扩展不会读取或保存 Cookie、Token、密码和非B站网页内容，也不会上传浏览记录。

## 数据

数据默认只存在当前浏览器。JSON导入采用“完整验证后覆盖”，各数据部分可单独清空。卸载扩展前应先导出备份。
